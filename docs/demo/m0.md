# M0 demo: the front door, sign-in and the org wall

The click-through for the M0 checkpoint (D114). Follow these steps while recording the walkthrough
with the Mac's screen recorder (D115).

## Before you start

- The one-time setup is done (D65): Caddy's local certificate is trusted, and the hosts file has
  `127.0.0.1 grc.localhost`.
- The stack is running: `docker compose -f packages/infra/compose.yaml --env-file .env up -d`.
- The demo logins exist. They come from `pnpm seed:demo`, which creates two orgs, Acme Corp
  (`@acme.example`) and Globex Ltd (`@globex.example`), with one user per role. It prints the login
  list.
- Every demo login uses the same password: the `DEMO_USER_PASSWORD` value in `.env`. It is never
  written here or printed.
- Have an authenticator app on your phone ready.

The demo uses the Risk Manager logins, `risk.manager@acme.example` and
`risk.manager@globex.example`. The automated sign-in test resets the Viewer logins on every run, so
leave those to it.

## Steps

1. Open http://grc.localhost in the browser. It moves you to https://grc.localhost, with a padlock
   and no certificate warning.
2. You are not signed in, so the app shows the sign-in page. Sign in with
   `risk.manager@acme.example` and the demo password.
3. The app asks you to set up two-factor sign-in (MFA is required for everyone). Enter the demo
   password again and press Continue.
4. Scan the QR code with your authenticator app, then press Continue.
5. Save the backup codes it shows (they are shown only once), tick "I have saved these backup
   codes" and press Continue.
6. Type the 6-digit code from the authenticator app and press "Verify and finish".
7. The workspace opens. The header shows the org name, Acme Corp, with your name and role (Risk
   Manager). The left navigation lists the screens.
8. Press Sign out in the header. You are back on the sign-in page; opening https://grc.localhost
   again keeps you there.
9. Sign in as `risk.manager@globex.example` with the same demo password, and set up two-factor
   sign-in the same way (steps 3 to 6).
10. The header now shows Globex Ltd. Nothing from Acme Corp appears anywhere: each org sees only
    its own workspace (the org wall).
11. Press Sign out.
